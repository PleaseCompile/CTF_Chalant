# 📻 The Radio Operator's Last Transmission

## 🎯 Concept (แนวคิดหลัก)

โจทย์นี้สอนเกี่ยวกับการถอดรหัสสัญญาณเสียงที่ใช้ในการสื่อสารยุคเก่า - รูปแบบการสื่อสารที่ใช้จุดและขีดแทนตัวอักษร

---

## 📖 Story (เนื้อเรื่อง)

ปี 1945 สงครามโลกครั้งที่ 2 กำลังจะสิ้นสุดลง...

คุณคือนักประวัติศาสตร์ที่กำลังค้นคว้าเอกสารลับในหอจดหมายเหตุแห่งชาติ ระหว่างที่คุณกำลังสำรวจกล่องเอกสารเก่าๆ คุณพบม้วนเทปโบราณที่มีป้ายกำกับว่า **"Final Transmission - TOP SECRET"**

หลังจากแปลงเสียงเป็นไฟล์ดิจิทัล คุณได้ยินเสียงที่แปลกประหลาด... **เสียงยาว-สั้น สลับกันไปมา** เหมือนจังหวะของเครื่องส่งสัญญาณโบราณ

ตามบันทึกระบุว่า: *"พันโท สมชาย เจ้าหน้าที่สื่อสารประจำสถานี ได้ส่งสัญญาณสุดท้ายออกไปก่อนที่สถานีจะถูกทิ้งร้าง เขาใช้รูปแบบการสื่อสารที่นักวิทยุสมัครเล่นทุกคนต้องรู้จัก"*

---

## 💡 Hints (คำใบ้)

### 🇹🇭 ภาษาไทย
1. **Hint 1:** ลองฟังดูดีๆ... เสียงสั้นกับเสียงยาว มันไม่ใช่แค่เสียงรบกวนธรรมดา
2. **Hint 2:** นักวิทยุสมัครเล่น (HAM Radio) รู้จักรูปแบบนี้ดี - **SOS** ก็ใช้แบบเดียวกัน
3. **Hint 3:** "จุด" กับ "ขีด" เป็นหัวใจของการสื่อสารยุคก่อนดิจิทัล
4. **Hint 4:** Samuel F.B. Morse คือผู้คิดค้นระบบนี้ในศตวรรษที่ 19
5. **Final Hint:** ลองค้นหา **"audio decoder dot dash"** ใน Google

### 🇬🇧 English
1. **Hint 1:** Listen carefully... short beeps and long beeps are not just noise
2. **Hint 2:** HAM Radio operators know this pattern well - **SOS** uses the same system
3. **Hint 3:** "Dots" and "Dashes" are the heart of pre-digital communication
4. **Hint 4:** Samuel F.B. Morse invented this system in the 19th century
5. **Final Hint:** Try searching **"audio decoder dot dash"** on Google

## 📦 Data File

ไฟล์: `transmission.wav`

ไฟล์เสียงนี้มีความยาวประมาณ 30 วินาที ประกอบด้วยเสียงที่เป็นรูปแบบเฉพาะ:
- เสียงสั้น (ประมาณ 0.1 วินาที)
- เสียงยาว (ประมาณ 0.3 วินาที)
- ช่วงเงียบระหว่างสัญญาณ

**หมายเหตุ:** สำหรับการทดสอบ สามารถใช้ข้อมูลในไฟล์ `morse_data.txt` แทน

## 🎮 Challenge

1. ดาวน์โหลดไฟล์ `transmission.wav` (หรือใช้ `morse_data.txt`)
2. วิเคราะห์รูปแบบเสียงในไฟล์
3. ระบุว่าเป็นการเข้ารหัสประเภทใด
4. ถอดรหัสเพื่อหา flag

---

## 🚩 Flag Format

```
flag{md5_hash}
```

**ตัวอย่าง:** `flag{5d41402abc4b2a76b9719d911017c592}`

3. ประวัติศาสตร์ของการสื่อสารทางไกล
